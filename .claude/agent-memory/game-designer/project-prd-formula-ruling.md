# PRD 伪随机分布公式裁决（阻塞 Story 4-4 AC-002）

2026-08-11 由 game-designer 做出的绑定裁决，纠正 ADR-0009（L228-245）与 GDD §9（L223-227）中数学上无法收敛的公式。

**Why:** 当前公式 `P_start = P_base = p`（标示概率），失败后 P 只增不减（恒 ≥ p），长期均值必然 > p。探针数据（C=0.05~0.30 时触发率 32.59%~40.06%，标示 30%）证实过度触发。根因是结构错误，非调参问题。

**How to apply:** 实现者（systems-designer / godot-gdscript-specialist）必须采用以下结构，不得沿用 ADR-0009 旧写法：

1. **起始值 = 校准常数 C**（不是 p）；**累加量 = C**（`P += C`，不是 `p×C`）；触发后重置为 C。
2. **C 语义 = 按标示值校准的查表常数**，恒 C < p；GDD 的 [0.3, 1.0] 累加倍数作废。
3. **30% 对应 C**：纯标准 PRD（无怜悯）= 0.11895（Dota 2 查表）；含怜悯 `ceil(1/0.3)=4` 连败强制 ≈ 0.108（数值重解）。
4. **怜悯保护保留**（AC-001 要求，不可移除），但必须把怜悯截断并入 C 校准——因为 `ceil(1/p)` 恒比 PRD 自然上限 `ceil(1/C)` 更严（30% 时 4 次 vs 9 次），直接套标准 C 表会让触发率偏高到 ~33.5%。

**C 求解公式**（每个 5% 步进 p 预计算）：
设 `M = ceil(1/p)`，`P(N=k) = min(1,k·C)·Π_{j=1}^{k-1}(1-min(1,j·C))`（k=1..M），`P(N=M+1)=Π(1-min(1,j·C))`（怜悯强制），`E[N]=Σ k·P(N=k)+(M+1)·P(N=M+1)`，令 `E[N]=1/p` 解 C。

**待钉死细节**：怜悯触发时点须在 ADR-0009 锁定为「连败达到 M 后第 M+1 次强制」（C≈0.108），而非「第 M 次即强制」（C≈0.073）。
