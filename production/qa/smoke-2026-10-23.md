## 新游戏无法开始 — 根因报告（非回归）

冒烟检查唯一 FAIL 项「新游戏无法开始」已定位根因，并确认与 sprint 15 改动无关。

**现象**：主菜单点击「新游戏」→ 无法进入身份选择界面，经错误恢复路径静默回退主菜单。

**根因**：`SceneManager.SCENE_PATHS`（`src/foundation/scene_manager.gd:67-80`）将 `SceneID.IDENTITY_SELECT` 映射到 `res://src/ui/identity_select/identity_select.tscn`，但该目录与场景文件**尚不存在**。`scene_transition.gd` 的错误恢复路径（AC-5 目标场景缺失 → 清理状态 + 回退 MAIN_MENU）按设计生效，故表现为「点新游戏回主菜单」。

**影响范围**：12 个注册场景中仅 `MainMenu.tscn` 与 `loading_screen.tscn` 已落盘；其余 10 个（identity_select / deck_editing / exploration / combat / tribulation / shop / event_panel / result_screen / defeat_screen / cultivation）均为占位路径，对应场景尚未由各自 UI/feature story 搭建。

**与 sprint 15 的关系**：无。此为预存在的**文档化留桩**——`main-menu/story-001-main-menu-scene.md` Completion Notes 已明确记载：

> 新游戏按钮转场目标 `identity_select.tscn` 尚不存在（身份选择 UI story 范围，Out of Scope）……AC-4 导航请求正确性已由 mock 测试覆盖；真实目标场景落地后此留桩自动消除，非缺陷。

`identity-selection-system` epic（Feature 层，`production/epics/identity-selection-system/EPIC.md`）当前为 Backlog，3 个 story（身份模板 / apply_identity / 查询 API）均 Not Started——身份选择 UI 场景本体属于其后继表现层 story，尚未进入任何 sprint。

**建议**：后续 sprint 规划时纳入「身份选择 UI 场景」story，落地 `identity_select.tscn` 并串联 SCENE_PATHS 后，此项自然消除。本 sprint 无需处理。
