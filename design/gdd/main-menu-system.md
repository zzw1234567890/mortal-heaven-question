## 概述

主菜单是游戏启动时首先展示的界面，提供新游戏、继续游戏、设置、退出等功能入口。设置界面管理游戏的所有可配置选项（音量、画面、按键绑定、语言等）。主菜单和设置是玩家对游戏的「第一印象」和「随时调整的后台」。

## 玩家幻想

主菜单的核心情感是**修仙世界的入口感**——玩家打开游戏的那一刻，就被氛围包裹。

| 情感 | 触发场景 |
|------|---------|
| **世界的召唤** | 启动游戏看到云海山脉缓缓流动——「我回来了」 |
| **旅程的起点** | 点击新游戏——「一切从这里开始」 |
| **回归的安心** | 有存档时继续游戏亮起——「上次修到哪了」 |
| **掌控的自由** | 设置中调整音量/按键——「按我的习惯来」 |
| **归属的确认** | 制作人员列表——「这群人创造了这个世界」 |

## 公式

主菜单系统不执行计算逻辑，仅提供界面入口和配置管理。

### 1. 设置项应用映射

```
apply_setting(category, key, value) → void:
  match category:
    "audio": audio_system.set_bus_volume(bus, db_from_percent(value))
    "graphics": ProjectSettings.set_setting(key, value)
    "keybind": InputMap.action_set_event(action, event)
    "language": TranslationServer.set_locale(value)
  save_to_config_file()
```

### 2. 音量百分比→dB 转换

```
db_from_percent(percent) → float:
  # 0% = -80dB (静音), 100% = 0dB (最大)
  if percent <= 0: return -80.0
  return linear_to_db(percent / 100.0)
```

## 边缘情况

- **无存档启动**：继续游戏按钮灰色不可用，玩家只能选择新游戏或设置
- **存档损坏**：点击继续游戏时检测到存档损坏，弹出提示「存档损坏，无法读取」，返回主菜单
- **设置应用失败**（如不支持的分辨率）：回退到上一个可用设置，弹出提示「该分辨率不支持，已恢复」
- **按键绑定冲突**：新按键已被其他功能绑定时，提示冲突并给出「覆盖/取消」选项
- **多存档槽**（如未来扩展）：继续游戏默认读取最近存档，可扩展为存档列表选择
- **设置未保存退出**：点击关闭未应用设置时提示「未保存的设置将丢失，确认退出？」
- **语言切换即时生效**：切换语言后界面文字即时更新，无需重启

### 边界澄清（2026-09-07，QL-STORY-READY）

- **音量生效/持久化时机**：音量滑条拖动**实时生效**到音频总线（即时可听变化）；但仅在点击「应用」时**持久化**写入设置文件。未保存关闭设置面板时，音量回滚到已保存值（AC-8「实时变化」指总线生效，非文件写入）。
- **「恢复默认」范围**：设置面板底部的**全局按钮**——一次重置音量/画面/按键绑定/语言全部设置为默认值（各分类不再单独设恢复按钮）。
- **AC-21 分辨率下限**：1280×720 为**支持分辨率下限**（control-manifest 2026-09-07 决策「不支持 1280×720 以下」）——AC-21 保留，验证 720p 下布局不溢出作为最低分辨率兼容性检查。
- **画质预设映射**：「低/中/高」映射到 Godot 渲染质量预设（`RenderingServer`/ProjectSettings 渲染缩放与效果开关组合），具体映射表由 story 003 实现时定义并数据驱动化。
- **可用分辨率列表来源**：Godot 4.6 分辨率枚举 API 待查证（`screen_get_resolutions()` 为 4.6 可能新增）——story 003 实现前查证引擎参考，查不到则安排 spike。
- **等待输入状态 ESC 语义**：按键绑定等待输入状态下按 ESC = **取消等待**返回列表（ESC 不作为可绑定键）。
- **语言切换刷新机制**：locale 变更信号 + 已显示控件重取翻译（非场景重载）。
- **键位持久化加载**：自定义按键写入设置文件后，游戏启动时须从设置文件加载并应用 InputMap（否则重启即失效）。
- **制作人员界面移除**（2026-09-19，QL-STORY-READY Story 001 裁决）：制作人员界面从 MVP 主菜单移除，整合到通关片尾（与 UX 规范 design/ux/main-menu.md L129 对齐）——主菜单为 4 按钮（新游戏/继续游戏/设置/退出）。
- **存档摘要数据源**：继续游戏按钮旁摘要「上次：[境界] · 游玩 [时长]」——realm 与 playtime 均取自 meta.json（chapter 不在 meta.json，不引入本 MVP；章节摘要待通关片尾/存档列表 story 再议）。
- **画面类生效时机统一**（2026-09-19，QL-STORY-READY Story 003 裁决）：分辨率/全屏/帧率/画质预设统一「点应用」生效（未保存关闭回滚，复用音量机制）；UX 规范已同步（应用按钮 10i + AC-SET-01）。「显示模式」独立下拉与全屏开关重叠——移出 MVP，仅实现全屏二态（Fullscreen/Windowed）。
- **音量总线映射与启动真值**（2026-09-19，QL-STORY-READY Story 002 裁决）：三滑条 → Master/BGM/SFX 一一对应（与 audio 001 总线表对齐，无 Music 总线）；启动音量真值 = 设置文件值覆盖 bus_layout 默认 dB（设置文件默认 100%=0dB）；启动加载行为归 audio 005。
- **恢复默认注册机制**（2026-09-19，QL-STORY-READY Story 003 裁决）：全局恢复默认 = 分类重置接口注册表——Story 003 实现注册机制并注册画面分类，002 注册音量分类，004/005 落地时各自注册；验收为「已注册分类全部重置 + 未注册分类占位不崩溃」。
- **减少动态效果**（2026-09-19，QL-STORY-READY Story 003 裁决）：UX 10d 开关入 story 003 scope（画面分类，含持久化+全局生效路径）。

## 验收标准

### 主菜单
- **GIVEN** 游戏启动，**WHEN** 加载完成，**THEN** 显示主菜单界面（标题+4个按钮+版本号）
- **GIVEN** 没有存档，**WHEN** 查看继续游戏，**THEN** 按钮灰色不可用
- **GIVEN** 有存档，**WHEN** 点击继续游戏，**THEN** 加载最近存档进入游戏
- **GIVEN** 主菜单，**WHEN** 点击新游戏，**THEN** 进入身份选择界面
- **GIVEN** 主菜单，**WHEN** 点击退出，**THEN** 游戏关闭

### 设置界面
- **GIVEN** 主菜单，**WHEN** 点击设置，**THEN** 打开设置界面（音效/画面/按键/语言4个分类）
- **GIVEN** 设置中修改音量滑动条，**WHEN** 拖动，**THEN** 对应总线音量实时变化（通过 `db_from_percent` 转换）
- **GIVEN** 设置中修改分辨率，**WHEN** 点击应用，**THEN** 画面分辨率改变（如不支持则回退+提示）
- **GIVEN** 设置中切换全屏/窗口，**WHEN** 点应用，**THEN** 显示模式切换（QL-STORY-READY 2026-09-19：画面类各项统一「点应用」生效）
- **GIVEN** 设置中修改帧率限制，**WHEN** 应用，**THEN** Engine.max_fps 更新
- **GIVEN** 设置中修改画面质量，**WHEN** 应用，**THEN** 渲染质量预设更新
- **GIVEN** 设置有未保存变更，**WHEN** 点击关闭，**THEN** 弹出「未保存设置将丢失」确认
- **GIVEN** 点击恢复默认，**WHEN** 确认，**THEN** 所有设置恢复为默认值

### 按键绑定
- **GIVEN** 按键绑定界面，**WHEN** 点击一个按键格，**THEN** 进入等待输入状态（闪烁「等待输入...」）
- **GIVEN** 等待输入状态，**WHEN** 按下新键，**THEN** 绑定更新+弹出确认
- **GIVEN** 按下新键已被其他功能绑定，**WHEN** 检测冲突，**THEN** 提示「该键已绑定 [功能名]，是否覆盖？」
- **GIVEN** 按键绑定界面，**WHEN** 点击恢复默认，**THEN** 所有按键恢复默认绑定

### 语言
- **GIVEN** 设置中切换语言，**WHEN** 应用，**THEN** 界面文字即时更新为新语言（无需重启，locale 信号刷新机制）

### 性能（非功能性）
- **GIVEN** 主菜单背景动画运行，**WHEN** 在 Godot 4.6 D3D12 渲染器下运行，**THEN** 帧时间 ≤16.6ms（60fps）
- **GIVEN** 1280×720分辨率，**WHEN** 查看主菜单，**THEN** 所有元素可见且不溢出屏幕
- **GIVEN** 主菜单，**WHEN** 运行，**THEN** Draw Call ≤50（背景+按钮+文字，无复杂 UI 元素）
