## 概述 (Overview)

本库记录「仙途问道」中所有可复用的交互模式。模式按类别组织，定义一致的行为、视觉表现和可访问性需求。每个 UX 规范通过模式名称引用本库，而非在每个屏幕中重新定义组件行为。

**设计原则**：
- 模式定义**行为**而非视觉——视觉由美术圣经 §7 驱动
- 模式从现有 UX 规范中**提取**——不凭空发明
- 新屏幕中发现的模式**追加**到本库——永不重复定义

## 模式定义 (Patterns)

### 按钮 (Button)

#### 主要按钮 (Primary Button)

**类别**：按钮
**使用屏幕**：主菜单、暂停菜单

**描述**：最显眼的操作按钮——表示玩家最可能执行的操作。默认焦点始终落在主要按钮上。

**规格**：
- 尺寸：280×44px（暂停菜单）/ 自适应宽度（主菜单）
- 边框：3px 浓墨色（默认）、3px 松石青（聚焦）
- 填充：暖白 #f5f0eb + 5% 浓墨悬停加深
- 字体：16px 墨色，中等粗细
- 悬停：墨色加深 15%，0.15s ease-out
- 按下：墨色加深 30%，0.1s，释放后弹回
- 键盘：Enter 激活当前聚焦的按钮
- 手柄：A 键激活
- 可访问性：对比度 ≥ 4.5:1（墨色在暖白上）。焦点指示器：松石青 2px 外部光环

**何时使用**：玩家最可能需要执行的操作——新游戏、继续游戏、继续（暂停）
**何时不使用**：危险操作使用危险按钮，次要导航使用次要按钮

---

#### 次要按钮 (Secondary Button)

**类别**：按钮
**使用屏幕**：主菜单、暂停菜单、HUD（暂停入口）

**描述**：标准导航按钮——不如主要按钮突出。用于频率较低但重要的操作。

**规格**：
- 尺寸：280×44px（暂停菜单）/ 自适应（主菜单）
- 边框：1.5px 淡墨色
- 字体：16px 墨色
- 悬停：边框加粗至 2px，填充 5% 淡墨，0.15s
- 其他交互同主要按钮

**何时使用**：设置、查看卡组、保存并退出、退出
**何时不使用**：默认操作（→ 主要按钮）、破坏性操作（→ 危险按钮）

---

#### 危险按钮 (Danger Button)

**类别**：按钮
**使用屏幕**：暂停菜单

**描述**：破坏性操作——不可逆或丢失进度。通过颜色、位置和间距与安全操作明确区隔。

**规格**：
- 同次要按钮尺寸
- 边框：1.5px 朱砂红（#c03a2b）
- 字体：16px 朱砂红
- 位置：通过分隔线与安全操作区隔
- 触发：左键点击 / Enter / A 键
- 结果：打开二次确认对话框
- 可访问性：四重信号——颜色（朱砂红）+ 图标（⚠）+ 位置（底部）+ 分隔线

**何时使用**：返回主菜单（放弃进度）、战败确认
**何时不使用**：可逆或非破坏性操作

---

#### 图标按钮 (Icon Button)

**类别**：按钮
**使用屏幕**：HUD（暂停入口、战斗日志折叠）

**描述**：以图标为主的紧凑按钮——墨水线框风格，透明填充背景。

**规格**：
- 尺寸：40×40px（暂停入口）/ 24×24px（战斗日志）
- 视觉：墨色线框 2px + 透明填充
- 悬停：线框加粗至 3px + 5% 淡墨填充
- 焦点：松石青 2px 外部光环
- 手柄：方向键导航到此按钮 → A 键激活

**何时使用**：HUD 角标位置（暂停、日志、地图）
**何时不使用**：主要菜单按钮（需要文字标签 + 更大点击区域）

### 面板 (Panel)

#### 面板 (Panel)

**类别**：面板
**使用屏幕**：所有屏幕

**描述**：内容容器——暖白基底、墨色边框、统一圆角。所有 UI 面板遵循同一视觉语言。

**规格**：
- 基底：暖白 #f5f0eb
- 边框：1px 墨色
- 圆角：4px（小面板）/ 8px（中面板 / 暂停面板）
- 内边距：20-24px
- 阴影：无——墨骨丹青风格不使用投影，依赖边框和留白建立层级
- 动画：面板弹入/弹出遵循各屏幕的过渡规范

---

#### 覆盖层 (Overlay)

**类别**：面板
**使用屏幕**：暂停菜单、设置、卡组查看

**描述**：覆盖在当前屏幕之上的模态面板——下方的交互被阻塞。

**规格**：
- 背景：暂停菜单和过渡提示为半透明黑色遮罩
- 面板在遮罩之上居中或从边缘滑入
- 关闭方式：点击遮罩（如允许）、ESC 键、关闭按钮
- 可访问性：打开/关闭通过 AccessKit 播报（待实现）

**何时使用**：必须阻断游戏交互的模态操作
**何时不使用**：非模态信息展示（→ 通知堆叠）

---

#### 遮罩层 (Mask Layer)

**类别**：面板
**使用屏幕**：暂停菜单、过渡提示

**描述**：覆盖全屏的半透明黑色遮罩——在覆盖层背后提供视觉阻断。

**规格**：
- 颜色：#000000
- Alpha：60%（暂停）/ 按场景变化（过渡提示）
- 效果：背景模糊（暂停菜单专用——Godot 4.6 BackBufferCopy + blur shader）
- 动画：淡入 0.2-0.25s，淡出 0.2-0.3s

**何时使用**：模式层（暂停、过渡）
**何时不使用**：轻量提示或非模态信息

---

### 对话框 (Dialog)

#### 确认对话框 (Confirmation Dialog)

**类别**：对话框
**使用屏幕**：主菜单、暂停菜单

**描述**：居中弹出的小型模态面板——打断当前操作并要求明确选择。

**规格**：
- 布局：居中，约 280-320px 宽
- 标题：H3 22px + 可选图标（⚠ 用于危险确认）
- 正文：Data 16px 墨色
- 按钮：[确认操作] [取消] —— 或三按钮变体（保存并退出/不保存/取消）
- 动画：淡入 + 轻微放大 scale 0.95→1.0，0.15s
- 关闭：ESC 关闭（等效取消）、手柄 B 键关闭
- 可访问性：焦点锁定在对话框内——Tab 在按钮间循环

**何时使用**：不可逆操作（返回主菜单、保存并退出）
**何时不使用**：可逆或低风险操作

---

#### 错误提示 (Error Alert)

**类别**：对话框
**使用屏幕**：暂停菜单

**描述**：系统操作失败时的反馈对话框——保存失败、加载失败。

**规格**：
- 同确认对话框尺寸和居中布局
- 标题：⚠ 图标 + 错误标题
- 正文：具体错误描述（保存失败→磁盘/权限；加载失败→损坏/不兼容）
- 按钮：[重试] [安全回退操作]
- 不关闭底层面板——玩家不会丢失上下文

**何时使用**：数据安全关键路径的失败场景
**何时不使用**：预期或非阻塞错误（→ 通知堆叠）

### 输入 (Input)

#### 滑块 (Slider)

**类别**：输入
**使用屏幕**：设置（音量控制）

**描述**：水平拖动条——控制连续值参数。

**规格**：
- 轨道：2px 淡墨 #b0a89b
- 填充：轨道左侧 100% 松石青
- 滑块手柄：12px 圆形，墨色 + 暖白填充
- 交互：鼠标拖拽 / ←→ 方向键 / 手柄肩键
- 反馈：调整过程中数值实时变化（音量预览）
- 可访问性：手柄 LB/RB 以 5% 步长调整，方向键以 1% 步长调整

**何时使用**：连续值参数（音量、灵敏度）
**何时不使用**：离散选项（→ 下拉菜单）、二元状态（→ 切换开关）

---

#### 切换开关 (Toggle)

**类别**：输入
**使用屏幕**：设置（减少动态效果、全屏）

**描述**：二元状态切换——开/关。

**规格**：
- 视觉：复选框或滑动切换——以美术圣经 §7 最终视觉为准
- 交互：左键点击 / Enter / 空格 / 手柄 A 键
- 反馈：开关状态即时视觉变化
- 状态：开（松石青高亮）/ 关（淡墨默认）
- 可访问性：标签声明当前状态（"减少动态：开"）

**何时使用**：二元设置项
**何时不使用**：多选项之间选择（→ 下拉菜单）

---

#### 下拉菜单 (Dropdown)

**类别**：输入
**使用屏幕**：设置（分辨率、帧率限制、画面质量、语言）

**描述**：点击展开选项列表——选择一个后列表收起。

**规格**：
- 触发器：点击显示当前值 → 选项列表向下展开
- 展开列表：暖白基底 + 1px 墨色边框 + 4px 圆角
- 选中项：松石青背景 + 墨色文字高亮标记
- 导航：↑↓ 方向键浏览选项，Enter/A 键确认
- 关闭：点击外部 / ESC / 选择后自动关闭
- 动画：列表从触发器向下滑出 0.15s

**何时使用**：3-10 个互斥选项的选择
**何时不使用**：2 个选项（→ 切换开关）、连续值（→ 滑块）

### 数据显示 (Data Display)

#### 进度条 (Progress Bar)

**类别**：数据显示
**使用屏幕**：HUD（修为、行动力、HP）

**描述**：线性填充条——可视化比例值（当前/上限）。

**规格**：
- 轨道：2px 淡墨线框
- 填充颜色：阈值切换——<50% 蓝 → 50-90% 紫 → ≥90% 金（修为）/ 松石青（行动力）/ 朱砂红（HP <20%）
- 尺寸：240×56px（境界修为）/ 72px 宽（角色 HP）/ 180px 宽（行动力）
- 更新事件驱动——非轮询
- 动画：平滑填充 0.3-0.4s ease-out
- 阈值闪烁：HP <20% = 0.5s 周期，修为 ≥90% = 1.0s 呼吸周期
- 可访问性：数字标签始终显示当前/上限值——不依赖颜色。色盲玩家通过长度和数字读取

**何时使用**：需要展示比例数据的场景
**何时不使用**：精确数值（→ 状态图标+计数器）、离散计数（→ 计数器）

---

#### 状态图标 + 计数器 (Status Icon + Counter)

**类别**：数据显示
**使用屏幕**：HUD（灵石、卡组、牌库、弃牌堆）

**描述**：小型图标配数字——用于资源数量、计数器和状态指示。

**规格**：
- 图标：24-28px 象形图标（灵石）/ 20px（牌库计数）
- 数字：Data 层级 20px 等宽数字，墨色常态
- 布局：图标 + 数字水平排列 HUD 资源栏
- 更新事件驱动——数值变更时触发
- 动画：数值跳动 scale 1.0→1.3→1.0，400ms
- 格式化：≥1000 显示 "1.2k"
- 阈值：卡组 = 上限时黄色，> 上限时红色闪烁 0.3s

**何时使用**：需要精确数值 + 快速扫读的场景
**何时不使用**：不需要精确数值（→ 进度条）、非数值状态（→ 状态图标）

---

#### 静态文本 (Static Text)

**类别**：数据显示
**使用屏幕**：所有屏幕（标题、版本号、进度信息）

**描述**：只读文本——不可交互。

**规格**：
- 字号层级遵循美术圣经 §7.2：H1 36px / H2 28px / H3 22px / H4 18px / Data 16px / Small 13px / Micro 10px
- 颜色：浓墨 #1a1a1a（主要内容）/ 淡墨 #8c8580（辅助信息）
- 对比度：≥ 4.5:1（浓墨在暖白上）
- 本地化：所有静态文本为字符串键——不硬编码

**何时使用**：任何不需要交互的文本元素
**何时不使用**：需要交互的文本（→ 按钮）

---

#### 悬停提示 (Tooltip)

**类别**：数据显示
**使用屏幕**：HUD（修为详情）、探索 UI（地图节点悬停）

**描述**：鼠标悬停在元素上时出现的浮动信息面板——显示该元素无法在主视图中容纳的额外数据。

**规格**：
- 外观：暖白基底 + 1px 墨色边框 + 4px 圆角
- 定位：跟随鼠标，偏移 12px——不遮挡被悬停的元素
- 触发：鼠标悬停 300ms 延迟显示
- 关闭：鼠标移开立即消失（无延迟）
- 字号：Small 13px 墨色
- 可访问性：键盘聚焦时等效显示——无鼠标专用

**何时使用**：辅助详情（精确数值、卡牌详情）
**何时不使用**：关键信息（→ 内联显示）、操作指令（→ 按钮标签）

### 通知 (Notification)

#### 通知堆叠 (Notification Stack)

**类别**：通知
**使用屏幕**：HUD

**描述**：可堆叠、自动消失的非模态通知——出现在中央顶部，不打断玩家操作。

**规格**：
- 位置：中央顶部，center-x，top: 72px
- 尺寸：每条 360×32px
- 堆叠上限：3 条
- 队列策略：FIFO——超量时丢弃最早的普通通知。系统通知和错误通知优先保留
- 持续时间：按类型——道具/卡牌/灵石/修为 2-3s、战斗事件 3s、系统/错误 4s
- 颜色编码：松石青（获得/正向）、琉璃金（稀有/灵石）、朱砂红（危险/错误）、淡墨（中性/系统）
- 交互：点击通知立即关闭
- 动画：出现时从顶部滑入 0.2s，消失时滑出+淡出 0.2s
- 可访问性：Screen reader 播报通知类型和内容（待实现）

**何时使用**：非阻塞的短暂反馈
**何时不使用**：阻塞性反馈（→ 对话框）、需要玩家确认的操作（→ 确认对话框）

### 导航 (Navigation)

#### 标签页导航 (Tab Navigation)

**类别**：导航
**使用屏幕**：主菜单、暂停菜单、设置

**描述**：键盘 Tab 键在可聚焦元素间的顺序移动。焦点顺序遵循视觉布局——自上而下、自左而右。

**规格**：
- 主菜单：标题（不可聚焦）→ 新游戏 → 继续 → 设置 → 退出 → 循环
- 暂停菜单：继续 → 查看卡组 → 系统设置 → 保存并退出 → 返回主菜单 → 循环（战斗中跳过保存并退出）
- Shift+Tab：反向遍历
- Enter / Space：激活聚焦元素
- ESC：关闭面板/对话框

**何时使用**：所有屏幕始终启用——不可选择退出
**何时不使用**：N/A——这是始终活跃的基础行为

---

#### 焦点环 (Focus Ring)

**类别**：导航
**使用屏幕**：所有屏幕

**描述**：可视化键盘/手柄焦点的指示器——松石青 2px 外部光环，标记当前聚焦的元素。

**规格**：
- 外观：松石青 #2d8f7f 2px 外部光环，圆角匹配元素圆角
- 键盘：Tab/Shift+Tab 移动焦点
- 手柄：方向键/左摇杆移动焦点
- 缺失时：键盘/手柄导航下不可见——焦点可能丢失
- 实现约束：Godot 4.6 双焦点系统——Control.focus_mode 必须显式地为所有交互式元素设罔为 FocusMode.ALL

**何时使用**：所有可聚焦元素——绝不省略
**何时不使用**：N/A

### 布局 (Layout)

#### 分隔线 (Divider)

**类别**：布局
**使用屏幕**：暂停菜单

**描述**：1px 水平线——将按钮组分隔为安全区和危险区。

**规格**：
- 视觉：1px 淡墨 #b0a89b
- 宽度：320px（暂停面板全宽）
- 间距：分隔线上方和下方各留空
- 目的：视觉分组——安全操作在上，危险操作在下

**何时使用**：当按钮组有不同的安全级别时（保存 vs 丢弃）
**何时不使用**：同质按钮组（→ 统一间距即可）

#### 按钮组 (Button Group)

**类别**：布局
**使用屏幕**：暂停菜单

**描述**：等宽竖排按钮——统一间距，排序反映信息层级。

**规格**：
- 布局：竖排，间距 8px
- 宽度：统一（280px 暂停菜单按钮）
- 排序：按使用频率——最常见在上，危险在底部
- 分隔：危险操作通过分隔线与上方组分隔

**何时使用**：2 个以上等宽竖排按钮
**何时不使用**：单按钮、混合宽度按钮、横排布局

**类别**：动画

**规格**：

**何时使用**：场�切换
**何时不使用**：面板级过渡（→ 覆盖层）、加载指示器（→ 本模式在持续 > 1s 时隐式包含加载态）

### 游戏专用 (Game-Specific)

#### 手牌布局 (Card Hand Layout)

**类别**：游戏专用
**使用屏幕**：战斗 HUD

**描述**：弧形排列玩家手牌——焦点卡放大，其余保持标准尺寸。

**规格**：
- 排列：弧形（曲率半径由牌数决定——7 张 vs 10 张）
- 牌尺寸：100×140px（手牌中），宽高比 5:7
- 悬停态：scale 1.2× + 上浮 10px + 完整牌面详情浮现——其余牌不位移
- 拖拽态：scale 1.1 + 下方 8px 淡墨阴影——跟随鼠杯
- 不可用态：40% 透明度 + 费用图标灰色——不可拖拽
- 溢出：>7 张堆叠，>10 张启用左右滚轮滚动
- 输入：鼠标拖拽 / 数字键 1-7 选择 / 手柄方向键选择 + A 确认打出
- 动画：抽牌飞入 300ms、打出飞向目标 400ms、重新排列 200ms ease-out

**何时使用**：战斗——出牌阶段
**何时不使用**：探索/商店/事件（→ HUD 资源栏）

#### 回合阶段指示器 (Turn Phase Indicator)

**类别**：游戏专用
**使用屏幕**：战斗 HUD

**描述**：战斗顶部居中水平进度条——显示当前阶段名 + 7 格进度跟踪。

**规格**：
- 视觉：H3 22px 浓墨当前阶段名 + 下方 4px 淡墨线框 ×7 格
- 7 阶段：备战 → 抽牌 → 行动 → 攻击 → 结束 → 结算 → 回合结束
- 更新：事件驱动——phase_changed 信号
- 动画：阶段切换文字 slide-in 200ms，进度格逐一填充 150ms
- 无玩家交互——只读显示

**何时使用**：战斗（始终在战斗中显示）
**何时不使用**：探索/商店/事件/地图选择
