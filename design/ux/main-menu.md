## Purpose & Player Need

主菜单是玩家进入「仙途问道」世界的门扉。它的首要任务不是列出功能，而是**在一瞥之间建立世界的基调**——宁静、克制、充满可能性。玩家在此停留的几秒钟内，应该感受到的不是紧迫的任务清单，而是一个等待被探索的修仙世界的呼吸。

美术圣经的「墨骨丹青」原则在此首次登场：黑白水墨为背景骨架，功能入口以克制的几何秩序呈现，仅在最关键的交互时刻（悬停、选中）引入语义色。这为玩家建立了一种潜意识契约——「这个游戏的视觉是有纪律的，色彩是有意义的」——这个契约将贯穿整个游戏体验。

**核心玩家需求**：
1. **开始或继续旅程** —— 新玩家想进入身份选择开始冒险，回归玩家想一键回到上次中断的位置
2. **调整环境** —— 在进入游戏世界之前或之中，玩家需要调整音量、画面、按键以适配自己的设备和习惯
3. **感知世界观** —— 在点击任何按钮之前，玩家已经通过视觉和听觉感受到这是一个修仙世界，而非通用卡牌游戏

如果主菜单做得不好：玩家会在进入游戏前就感到这是一款"功能堆砌"的产品而非有灵魂的作品，第一印象的修复成本极高。

## Player Context on Arrival

主菜单在三种截然不同的玩家状态下被访问，每种状态要求不同的响应优先级：

**场景 1：初次启动（新玩家）**
玩家刚购买并安装游戏，带着明确的目标——「开始玩」。他们没有耐心阅读冗长的开场动画或教程提示。主菜单需要在 **2 秒内让玩家找到「新游戏」按钮**，同时用背景的视觉氛围（水墨云海、道乐）在潜意识层面传递世界观。这是一个「让他尽快开始，但让他在快速操作中瞥见世界」的平衡——功能入口必须突出，氛围是锦上添花而非障碍。

**场景 2：惯性回归（老玩家）**
玩家已经玩了几十个小时，打开游戏是肌肉记忆——双击图标，看到主菜单，点「继续游戏」，进入。主菜单在此场景中的角色是**零摩擦中转站**——「继续游戏」必须是视觉上最突出的选项（默认焦点），一切不应该让玩家多花 0.5 秒寻找。如果上次玩是在昨天，点继续就是回到昨天的地方；如果上次玩是上个月，一个简短的「上次：元婴期，第 2 章」提示帮助老玩家找回记忆。

**场景 3：退回标题（结束/清空）**
玩家从暂停菜单选择「返回标题界面」。此时他们处于结束/清空的心理状态——刚结束一局（可能是胜利后的满足，也可能是失败后的沮丧），需要一个**干净、无情绪的重新开始**。主菜单在此场景中不应庆祝也不应安慰——只需平静地呈现所有入口，让玩家自主选择下一步。此时「继续游戏」仍然保留（以防误操作），但「新游戏」与它视觉同级而非被压过。

## Navigation Position

主菜单位于游戏导航层级的**根节点**。它是所有玩家旅程的起点和游戏的公共客厅。

```
[游戏启动 / Steam]
       │
       ▼
  ┌─────────┐
  │ 主菜单   │ ← 根节点
  └────┬────┘
       │
  ┌────┼────────┬──────────┬────────┐
  ▼    ▼        ▼          ▼        ▼
 新游戏 游戏内   设置      退出→    桌面
 (身份选择)(读档)
```

**替代进入路径**：游戏中暂停菜单 → 返回标题界面 → 主菜单。此路径通常发生在一局结束时或玩家主动放弃当前局时。

主菜单是**始终可达**的（从暂停菜单），但正常游戏流程中不应被频繁访问——如果玩家每局需要多次返回主菜单，说明游戏内缺少某种导航路径。

## Entry & Exit Points

| 进入来源 | 触发器 | 玩家携带的上下文 |
|-----------|--------|-------------------|
| 游戏启动 | 双击启动 / Steam 播放 | 无（冷启动）或上次存档元数据（检测存档存在性） |
| 暂停菜单 | 点击"返回标题界面" | 当前局进度（境界、章节、已有时长）——确认对话框已处理 |

| 退出目的地 | 触发器 | 备注 |
|------------|--------|------|
| 身份选择 | 点击"新游戏" | 进入开局身份选择流程；不可逆——身份选择有确认步骤但一旦确认即开始新游戏 |
| 游戏内（读档） | 点击"继续游戏" | 读取最近存档直接进入游戏；无存档时按钮灰色不可用——不可逆（已进入游戏） |
| 设置界面 | 点击"设置" | 覆盖在主菜单之上的面板/子界面；可逆——关闭设置即返回主菜单 |
| 桌面 | 点击"退出" | 关闭游戏进程；Steam 覆盖层可拦截确认 |

## Layout Specification

### Information Hierarchy

```
【第一眼 —— 必须立即可见】
  1. 游戏标题「仙途问道」
  2. 新游戏按钮
  3. 继续游戏按钮（有存档时高亮，无存档时灰色但占位保留）

【第二眼 —— 可被引导发现】
  4. 设置按钮
  5. 退出按钮

【第三眼 —— 不争抢注意力】
  6. 存档状态摘要（"上次：元婴期，第 2 章" —— 轻量文本，在继续按钮旁）

【最底层 —— 几乎不可被注意但仍存在】
  8. 版本号（角落）
  9. 背景动态场景（永远存在但不是"信息"——是氛围层）
```

### Layout Zones

选择方案 **B：「左序右境」**——左侧几何秩序承载功能，右侧有机气韵承载世界。

| 区域 | 位置 | 视觉语法 | 用途 |
|------|------|----------|------|
| **标题与导航栏** | 左上区域（约屏幕 1/3 宽度） | 几何秩序——锐利边框、统一间距 | 游戏标题 + 5 个功能按钮垂直排列 |
| **世界展示区** | 右侧 2/3 + 左侧空白区域 | 有机气韵——水墨笔触、留白、动态场景 | 水墨云海动态背景 |
| **状态栏** | 底部条（全宽极窄） | 几何秩序——小字、低调 | 版本号 + Steam 标识 |

## States & Variants

主菜单状态相对精简，核心变体只有存档存在性驱动的差异，加上一个覆盖层面板。

| 状态 / 变体 | 触发器 | 变动部分 |
|-------------|--------|----------|
| **默认（有存档）** | 检测到 ≥1 个存档 | 继续游戏高亮可用 + 按钮下方显示存档摘要（「上次：境界·章节」） |
| **空（无存档）** | 检测到 0 个存档 | 继续游戏按钮灰色禁用 + 不显示存档摘要行；按钮保留占位以维持布局稳定性 |
| **设置面板打开** | 点击「设置」 | 半透明暗色遮罩覆盖主菜单；设置面板从右侧滑入或居中弹出；主菜单按钮不可交互 |
| **返回标题确认** | 暂停菜单 → 返回标题界面 | 确认对话框居中弹出：「确定返回标题界面？未保存的进度将丢失。」+ [确定] [取消] |
| **退出** | 点击「退出」 | 直接退出——无确认对话框 |

## Interaction Map

正在映射交互：鼠标（主要）+ 键盘，手柄部分支持。

### 主菜单按钮

| # | 组件 | 动作 | 鼠标 | 键盘 | 手柄 | 即时反馈 | 结果 |
|---|------|------|:--:|:--:|:--:|------|------|
| 2 | **新游戏** | 点击 | 左键 | Enter | A | 按钮按下态（墨色加深 0.3s）+ 水墨笔触声 | 导航 → 身份选择界面 |

| # | 组件 | 动作 | 鼠标 | 键盘 | 手柄 | 即时反馈 | 结果 |
|---|------|------|:--:|:--:|:--:|------|------|

### 焦点导航顺序

键盘 Tab / ↑ ↓ / 手柄方向键在主菜单按钮间导航：
```
标题(不可聚焦) → 新游戏 → 继续游戏 → 设置 → 退出 → 循环回新游戏
```

设置面板内：自上而下的焦点顺序，分组间可跳转。

## Events Fired

| 玩家动作 | 触发的事件 | 载荷 / 数据 | 备注 |
|-----------|------------|-------------|------|
| 点击「新游戏」 | `MAIN_MENU_NEW_GAME` | `{timestamp}` | 游戏内首次分析事件——标记新玩家进入流程 |
| 点击「继续游戏」 | `MAIN_MENU_CONTINUE` | `{timestamp}` | 标记回归玩家 |
| 点击「退出」 | 无 | — | 退出不需追踪；Steam 自有 session 统计 |
| 打开设置面板 | `SETTINGS_OPENED` | `{source: "main_menu"}` | 来源区分主菜单 vs 游戏内暂停 |
| 修改任何设置项 | `SETTINGS_CHANGED` | `{setting: "volume_master", old: 80, new: 60}` | 用于调试和默认值分析 |
| 点击「恢复默认」 | `SETTINGS_RESET` | `{timestamp}` | — |
| 关闭设置面板 | `SETTINGS_CLOSED` | `{timestamp}` | — |
| 返回标题确认-确定 | `RETURN_TO_TITLE` | `{from_state: "paused", progress_lost: true}` | 安全网——追踪玩家放弃进度的频率 |
| 返回标题确认-取消 | `RETURN_TO_TITLE_CANCELLED` | `{from_state: "paused"}` | 衡量误触率 |

## Transitions & Animations

### 屏幕级过渡

| 过渡 | 动画 | 时长 | 缓动 | 说明 |
|------|------|:--:|------|------|
| **主菜单进入（冷启动）** | 黑屏 → 墨滴入水从中心向外晕开，露出主菜单 | 0.6-0.8s | ease-out | 覆盖游戏启动加载的结尾——加载完成与动画起始无缝衔接。水墨晕染从中心向外扩散，先露出标题再露出按钮区，最后露出背景 |
| **主菜单 → 新游戏** | 墨色从外向内收敛至中心黑洞，然后淡入身份选择 | 0.4-0.5s | ease-in | 暗示"进入一个新世界"——收敛点与标题位置对齐 |
| **主菜单 → 继续游戏** | 同新游戏退出 + 加载过渡 | 0.4-0.5s | ease-in | 加载完成后画面从中心向外晕开 |
| **暂停 → 返回主菜单** | 画面整体淡出至黑 + 淡入主菜单（比冷启动更快） | 淡出 0.2s + 淡入 0.3s | linear | 不做完整晕染——玩家在退出状态，不需要仪式感，需要效率 |
| **主菜单 → 退出桌面** | 墨色从外向内收敛 | 0.3-0.4s | ease-in | 收敛至屏幕中心后窗口关闭 |

### 面板级过渡

| 过渡 | 动画 | 时长 | 说明 |
|------|------|:--:|------|
| **设置面板打开** | 从右侧滑入（覆盖左 1/3 留出背景可见） | 0.25s | ease-out | 面板不覆盖全屏——保留右侧水墨世界的一部分可见，维持空间感 |
| **设置面板关闭** | 滑回右侧 | 0.2s | ease-in | 比打开更快——关闭不需要展示信息 |
| **返回标题确认对话框** | 居中淡入缩放（95% → 100%） | 0.2s | ease-out | 轻量、不打扰——只是一个确认动作 |

### 状态内微动画

| 动画 | 触发器 | 描述 |
|------|--------|------|
| **背景云海循环** | 持续 | 云层缓慢横移（~60px/s），远山视差层叠。永不停歇——即使设置面板打开也继续 |
| **按钮悬停** | 鼠标悬停 | 墨色加深 15%，0.15s ease-out。无缩放——克制 |
| **按钮按下** | 点击 | 墨色加深 30%，0.1s。释放后弹回悬停态或默认态 |
| **存档摘要出现** | 检测到存档 | 继续游戏按钮下方文本淡入，0.3s delay 后出现（让按钮先渲染） |
| **标题入场** | 冷启动晕染到达标题区 | 标题逐字淡入，每个字间隔 0.05s，"仙"字最后出现且附带微妙的笔触轨迹动画 |

### 动效减少模式

当玩家在设置中启用了「减少动态效果」（无障碍选项）：
- 所有水墨晕染/收敛动画降级为简单淡入淡出
- 背景层叠视差降为静态图像
- 按钮悬停/按下效果保持（功能性反馈不禁用）
- 标题入场动画跳过——所有文字直接显示

| 检查项 | 状态 | 具体措施 |
|--------|:--:|------|
| **纯键盘导航** | ✅ 已覆盖 | 见交互地图焦点顺序 — 所有可交互元素可通过 Tab / ↑ ↓ 访问，ESC 关闭面板和对话框 |
| **手柄导航** | ✅ 已覆盖 | 见交互地图 — 部分手柄支持（A 确认、B 取消/返回、方向键/肩键导航） |

| **不依赖颜色** | ✅ 已满足 | 继续游戏通过「灰色 + 文本不可用 + 无摘要行」三重独立信号表达不可用状态——并非仅靠颜色区分 |
| **焦点指示器** | ✅ 设计约束 | 所有可聚焦元素需有可见焦点边框（墨色外发光或轮廓线），键盘/手柄导航时始终可见 |

| **动态效果** | ✅ 已覆盖 | 过渡与动画中已定义「动效减少模式」——所有晕染/收敛动画降级为淡入淡出，背景视差降为静态 |
| **启动过渡** | ⚠️ 关注 | 冷启动水墨晕染 0.6-0.8s 不应包含闪烁或快速交替的图案——避免触发光敏反应。动画为纯暗色渐变，风险低 |

## Localization Considerations

| 关注点 | 风险 | 措施 |
|--------|:--:|------|
| **按钮标签** | ⚠️ 中 | 「新游戏」3 字、「继续游戏」4 字、「设置」2 字、「退出」2 字。翻译到英语：`New Game` (8 chars)、`Continue` (8 chars)、`Settings` (8 chars)、`Quit` (4 chars)。按钮宽度需预留 40% 膨胀空间而不换行 |
| **存档摘要文本** | 🔴 高 | 「上次：元婴期·第 2 章」是可变内容——境界名称（如「炼气期」vs「化神期」）和章节编号长度在各语言中差异显著。英语中 `Last: Nascent Soul·Chapter 2` 显著更长。建议按钮允许摘要行使用更小字号或截断（省略号），而非强制一行 |
| **设置面板标签** | ⚠️ 中 | 「总音量」「音乐音量」「音效音量」「按键绑定」「游戏语言」「恢复默认」——最长 4 中文字。英语 `Master Volume`/`Key Bindings`/`Restore Defaults` 膨胀 2-3×。左侧标签宽度需允许到 ~18 英文字符 |
| **按键绑定界面** | ⚠️ 中 | 功能名称列（如「出牌-卡牌1」「暂停/菜单」）在各语言中差异大。表格需自适应用列宽 |
| **返回标题确认对话框** | ⚠️ 中 | 「确定返回标题界面？未保存的进度将丢失。」——德语变体可能长达 1.5×。对话框宽度需灵活，不固定像素 |
| **版本号** | ✅ 低 | `v0.1.0` 数字格式通用，不受本地化影响 |

## Acceptance Criteria

- [ ] **AC-PERF-01**：冷启动后主菜单在 2 秒内完成渲染并可交互（含水墨晕染过渡动画）
- [ ] **AC-NAV-01**：点击「新游戏」后，画面过渡至身份选择界面，过渡时间 ≤ 0.8s
- [ ] **AC-EMPTY-01**：无存档时「继续游戏」按钮灰色禁用，点击无响应；有存档时高亮可用，按钮下方显示存档摘要文本
- [ ] **AC-A11Y-01**：全部可交互元素（新游戏、继续游戏、设置、退出、设置面板内各控件）可通过 Tab 键依次聚焦，可通过 Enter 键激活；ESC 键关闭设置面板和确认对话框
- [ ] **AC-CORE-01**：从暂停菜单点击「返回标题界面」后弹出确认对话框；确定后返回主菜单，取消后回到暂停菜单
- [ ] **AC-SET-01**：设置面板中修改音量滑块时，音量实时变化；修改分辨率/全屏/帧率/画面质量时即时生效；修改语言时即时切换，无需重启
