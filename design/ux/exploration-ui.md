## Purpose & Player Need

**核心目的**：探索 UI 是玩家在修仙世界中的「地图」——它将探索系统的节点图状态、行动力数据、迷雾机制转化为玩家可理解、可规划的视觉界面。玩家在这里做的是**路线规划**：看全貌、辨风险、算资源、选道路。这是支柱 3「机缘巧合，意外之喜」（未知节点的好奇）和支柱 2「苟道成长，步步为营」（路线的风险权衡）的落地界面。

**玩家需求**：

1. **路径的可见性**——玩家能一眼看到地图全貌、当前位置、可选路径、剩余行动力。节点图的分叉结构必须清晰可读，让「左边事件还是右边战斗」成为一眼可做的选择。
2. **风险的预判**——战斗节点的敌人详情、Boss 节点的距离、行动力是否够用，这些决策信息要在点击前可见（悬停预览）。
3. **未知的好奇**——迷雾节点的存在要勾起好奇心（「那里面是什么？」），而不是纯粹的视觉噪音。
4. **掌控的安心**——玩家随时知道自己在哪张地图、第几层、离 Boss 多远、行动力还剩几步——不需要打开任何面板就能扫读到核心状态。
5. **离开的自由**——玩家能主动结束探索（「✕结束探索」），不被困在地图里。

**完成这句话**：「玩家打开探索 UI 时想要——看清前路，规划我的下一步，并确信自己不会误入死路。」

**GDD 需求约束**（来自 `exploration-ui-system.md` §用户界面需求）：
- 11 个界面需覆盖：地图选择界面、节点图主界面、行动力指示器、节点交互弹窗、Boss战前确认、重入确认弹窗、探索结束面板、地图通关结算、新地图解锁提示、地图状态概览、卡组查看面板
- 10 种节点类型的图标+颜色映射（入口/战斗/精英/Boss/事件/商店/传送/灵泉/渡劫台/回复点）
- 两个必须在 UX 阶段解决的阻塞项：节点图缩放（问题#1）、同层路径选择（问题#2）
- AP 颜色阈值：>30% 蓝 / >10% 黄 / ≤10% 红+闪烁
- 分辨率基准 1920×1080

## Player Context on Arrival

**首次遇到此屏幕的时机**：新档开局完成身份选择后，进入第一张地图（青云剑宗·低）——玩家第一次看到地图选择界面，然后选择未通关地图进入节点图。这是玩家在游戏中的第二个主要界面（主菜单之后）。

**到达前玩家刚在做什么**：
- **地图选择界面**：从主菜单/上一张地图通关结算/探索结束面板到达——玩家刚做完「去哪张图」的宏观决策
- **节点图主界面**：从地图选择进入（地图加载动画），或从战斗/事件/商店返回（节点交互完成）
- **节点交互弹窗**：刚点击了战斗/商店/灵泉/回复点节点——玩家在做「进不进」的微观决策

**设计应假设的情绪状态**：
- **从容规划态**——探索无时间压力（战斗中才有紧张感），玩家以放松但专注的状态规划路线
- **好奇+谨慎并存**——迷雾节点勾起好奇，战斗节点引发谨慎评估
- **资源焦虑（后期）**——行动力低于 30% 时黄色警告触发轻微紧迫感

**玩家是自愿到达此屏幕还是被游戏送到这里**：
- 地图选择：自愿——玩家主动选择探索目标
- 节点图：半自动——选择地图后自动进入
- 探索结束面板：被动触发——行动力归零时自动弹出；主动触发——玩家点击「✕结束探索」

**旅程上下文缺口**：`design/player-journey.md` 不存在。设计假设基于 GDD 玩家幻想段落（「路线的预览」「距离的感知」「未知的好奇」等 5 种情感）推断。

## Navigation Position

探索 UI 由两个层级的界面组成——**地图选择界面**（宏观决策）和**节点图主界面**（微观执行），后者是探索阶段的核心驻留界面。

**地图选择界面位于**：

```
[根] → [主菜单] → [新游戏/继续游戏] → [地图选择界面]
                                ↑
              [通关结算确认] / [探索结束确认] ─┘（返回地图选择）
```

**节点图主界面位于**：

```
[地图选择界面] → [地图加载] → [节点图主界面]（探索阶段驻留）
```

**导航性质**：
- 地图选择——顶级目的地（探索阶段的入口，每次探索开始/结束时回到这里）
- 节点图——上下文相关（仅探索进行中存在，同时是探索阶段的中心枢纽：战斗/事件/商店/卡组查看都从这里进出）

**从节点图出发的子导航**：
- 节点交互 → 战斗 UI（战斗节点）/ 事件面板（事件节点）/ 商店界面（商店节点）
- 卡组查看面板（随时可开，非模态覆盖）
- 地图状态概览面板（信息按钮打开）
- 暂停菜单（ESC）

**HUD 关系**：探索场景中全局 HUD 可见（境界/修为条、灵石、卡组数量、行动力、暂停入口）——与战斗场景相反（战斗中 HUD 隐藏）。节点图上的行动力指示器与 HUD 右下行动力显示同一数据源。

## Entry & Exit Points

### 地图选择界面

| 进入来源 | 触发器 | 玩家携带的上下文 |
|---|---|---|
| 主菜单-新游戏 | 身份选择确认 | 初始卡组、初始角色、境界（炼气） |
| 主菜单-继续游戏 | 读档完成 | 存档中的卡组/境界/地图解锁状态 |
| 通关结算 | 点击「确认」 | 通关奖励已入账、新地图解锁状态 |
| 探索结束面板 | 点击「返回地图选择」 | 本次探索收集摘要已展示 |

| 退出目的地 | 触发器 | 备注 |
|---|---|---|
| 节点图（未通关地图） | 点击未通关+境界达标卡片 | 直接进入（0 灵石） |
| 节点图（已通关地图） | 重入确认弹窗「确认传送」 | 扣除重入灵石，生成新节点图——不可逆（灵石已扣） |
| 新地图解锁提示 | 突破后自动弹出 | 多张地图列表展示，「前往查看」回到本界面 |

### 节点图主界面

| 进入来源 | 触发器 | 玩家携带的上下文 |
|---|---|---|
| 地图选择 | 进入未通关/重入确认 | 满行动力、新节点图、入口节点定位 |
| 战斗 UI-胜利 | 战利品确认后场景切换 | 奖励入账、当前节点标记已访问 |
| 战斗 UI-战败/撤退 | 结算确认后 | 修为损失、返回节点图或主菜单（视规则） |
| 事件面板 | 事件完成 | 事件结果已应用 |
| 商店界面 | 点击「离开」 | 购买/删卡/出售变更已入账 |

| 退出目的地 | 触发器 | 备注 |
|---|---|---|
| 战斗 UI | 战斗节点确认弹窗「进入战斗」 | 不可逆——进入战斗后节点图冻结 |
| 事件面板 | 事件节点交互 | 事件结果决定后续 |
| 商店界面 | 商店节点确认「进入商店」 | 商店关闭返回节点图 |
| 通关结算 | Boss 击败 | 不可逆——地图通关 |
| 探索结束面板 | 行动力归零（自动）/「✕结束探索」（主动） | 主动离开需确认弹窗 |
| 暂停菜单 | ESC / 暂停按钮 | 可逆——暂停冻结 |

**不可逆操作汇总**：
- 重入确认「确认传送」——灵石扣除
- Boss 战「进入战斗」——撤退视为战败
- 渡劫台交互——触发渡劫战后退路受限（80% 修为损失警示）

## Layout Specification

### Information Hierarchy

**节点图主界面**（信息按优先级分层）：

| 优先级 | 信息 | 位置层级 | 理由 |
|---|---|---|---|
| **P0** | 节点图本体（节点+路径+迷雾） | 屏幕中央、全屏画布 | 路线规划的核心——玩家 80% 的注意力在这里 |
| **P0** | 当前位置（玩家标记） | 节点图上的高亮节点 | 「我在哪」——所有规划的锚点 |
| **P0** | 可选路径（可达节点高亮） | 节点图上的路径/节点视觉状态 | 「下一步去哪」——即时决策对象 |
| **P1** | 行动力剩余（大数字+颜色阈值） | 右下角（与 HUD 同数据源，节点图侧强化显示） | 「还剩几步」——规划的资源约束 |
| **P1** | 节点悬停预览（类型/敌人详情/AP 消耗） | 悬停时浮出的 tooltip | 「进不进」——点击前的决策信息 |
| **P1** | Boss 节点距离/方向 | 节点图上的 Boss 图标（可见即知） | 宏观目标感知 |
| **P2** | 层数/进度指示（第几层，共几层） | 顶部条或地图边缘 | 扫读信息，不需持续注视 |
| **P2** | 地图名称 | 顶部条 | 身份确认，低频查看 |
| **P2** | 已访问/未访问节点状态 | 节点图上的视觉标记 | 规划参考 |
| **P3** | 卡组数量入口 | HUD，不重复 | 点开卡组查看面板即可 |
| **P3** | 灵石/境界 | HUD，不重复 | 探索决策低频使用 |
| **P3** | 地图状态概览入口（信息按钮） | 边角按钮 | 按需查看 |

**关键设计原则**：
- **P0 全屏画布**：节点图占满中央区域，HUD 元素靠边不遮挡
- **悬停预览是 P1 而非 P0**：风险信息在玩家主动查询时展示（悬停），避免地图上同时显示 10 种节点详情造成的视觉噪音——迷雾的「未知」感也依赖这种克制
- **AP 双显示**：HUD 右下角有行动力，节点图侧强化为大号显示（规划时视线聚焦地图中心，需余光可读 AP）
- **AP 颜色阈值**（来自 GDD）：>30% 蓝 / >10% 黄 / ≤10% 红+闪烁

**地图选择界面**：P0 = 地图卡片（名称/难度/解锁状态/通关状态/境界要求）→ P1 = 灵石余额（重入扣费参考）→ P2 = 探索统计（历史）

**节点交互弹窗（战斗/商店/灵泉等）**：P0 = 节点类型与确认操作 → P1 = 风险/收益详情（敌人构成、商品列表）→ P2 = AP 消耗与结果预览

#### GDD 阻塞项决策记录（UX 阶段解决）

| 阻塞项 | 决策 | 理由 |
|---|---|---|
| **#1 节点图缩放** | 滚轮缩放（50%-150%）+ 边缘/中键平移，默认整图自动适配屏幕 | 玩家自由选择宏观概览或局部细察；默认适配保证「一眼看全貌」零操作成本 |
| **#2 同层路径选择** | 直接点击目标可达节点，系统自动路由 | 零学习成本，所有可达节点常亮，点哪个去哪个 |

## States & Variants

| 状态 / 变体 | 触发器 | 变动的部分 |
|---|---|---|
| **默认（节点图驻留）** | 进入地图后正常加载 | — |
| **空（无可达节点）** | 理论上不出现——AP 归零时自动弹出探索结束面板；若因 bug 出现则显示错误提示+强制结束探索按钮 | 节点图区域显示异常提示横幅 |
| **加载（地图生成）** | 从地图选择进入/重入确认后 | 中央画布显示地图加载动画（迷雾汇聚效果 ~1.5s），顶部条与 HUD 立即可见 |
| **加载（节点交互返回）** | 战斗/事件/商店完成返回 | 短暂切换动画（~0.5s），节点状态更新（当前节点标记已访问） |
| **缩放 50%/100%/150%** | 滚轮操作 | 节点图标/文字随缩放等级联动（50% 时隐藏节点文字标签只留图标） |
| **AP 充足（>30%）** | AP 比例 >30% | AP 显示蓝色，正常状态 |
| **AP 警告（>10%）** | AP 比例 ≤30% 且 >10% | AP 显示黄色 |
| **AP 危急（≤10%）** | AP 比例 ≤10% | AP 显示红色+闪烁动画 |
| **AP 归零（自动结束）** | AP = 0 | 短暂延迟（~1s）后自动弹出探索结束面板（期间播放 AP 归零音效） |
| **迷雾揭示瞬间** | 玩家移动到新节点，相邻迷雾揭开 | 揭雾动画（迷雾消散 ~0.8s），揭示的节点弹入 |
| **节点悬停** | 鼠标悬停在节点上 | 该节点放大 110%，浮出预览 tooltip，可达路径高亮加强 |
| **Boss 邻近警示** | 当前位置与 Boss 节点同层/相邻 | Boss 节点呼吸发光动画（提示宏观目标） |
| **渡劫台交互警示** | 点击渡劫台节点 | 弹出渡劫确认弹窗，显示 80% 修为损失警告（朱砂红高亮） |
| **暂停** | ESC / 暂停按钮 | 全屏变暗+暂停菜单（与全局暂停菜单一致，节点图冻结） |
| **弹窗打开** | 节点交互/Boss 确认/重入确认 | 节点图输入冻结（缩放/平移/点击均无效），弹窗居中 |
| **探索结束面板** | AP 归零自动 / ✕主动确认 | 全屏面板覆盖，含收集摘要 |
| **通关结算** | Boss 击败返回 | 通关结算面板（含奖励列表+新地图解锁提示） |
| **教程覆盖（首次进入）** | 新档首次进入第一张地图 | 首次进入节点图时显示简短教程提示（3 步：看路径→看AP→点击移动），任意点击跳过 |

**手柄变体**：光标移动映射方向键，A=确认（等效点击），B=取消/关闭弹窗，Start=暂停；缩放平移改用 LB/RB（缩放）+ 方向键（平移，缩放激活时）。

| 玩家动作 | 触发的事件 | 载荷 / 数据 |
|---|---|---|

| 节点交互弹窗-确认（战斗） | `battle_node_confirmed` | `{node_id, enemy_group_id}` |
| 节点交互弹窗-确认（商店） | `shop_node_confirmed` | `{node_id, shop_seed}` |
| 节点交互弹窗-确认（灵泉/回复点） | `heal_node_confirmed` | `{node_id, heal_amount}` |
| 节点交互弹窗-取消 | `node_interaction_cancelled` | `{node_id}` |
| Boss 确认弹窗-进入战斗 | `boss_battle_entered` | `{node_id, boss_id}` |

| 重入确认弹窗-确认传送 | `map_reentry_confirmed` | `{map_id, cost_lingshi}` — **持久变更（灵石扣除）** |
| 重入确认弹窗-取消 | `map_reentry_cancelled` | `{map_id}` |
| 点击未通关地图卡片 | `map_entered` | `{map_id, is_first_visit}` |
| AP 归零（自动） | `exploration_auto_ended` | `{map_id, layer_reached, reason: "ap_zero"}` |
| 结束探索确认 | `exploration_ended_manually` | `{map_id, layer_reached}` |
| 通关结算-确认 | `map_cleared` | `{map_id, rewards: {...}}` — **持久变更（奖励入账+新地图解锁）** |
| 新地图解锁提示-前往查看 | `new_map_unlocked_viewed` | `{map_ids: [...]}` |
| 缩放操作 | `map_zoom_changed` | `{zoom_level}` |
| 首次教程完成/跳过 | `tutorial_skipped` | `{step_reached}` |

**标记持久游戏状态的动作**（架构团队特别关注）：
- `map_reentry_confirmed` — 灵石扣除
- `map_cleared` — 奖励入账+新地图解锁
- `node_entered` — 玩家位置/AP 变更（存档点）

**无事件动作**：节点悬停、缩放平移（纯视图操作）、弹窗内导航（不改变游戏状态）——`map_zoom_changed` 保留用于分析（可选）。

## Transitions & Animations

### 屏幕进入/退出过渡

| 过渡 | 规格 |
|---|---|
| **地图选择→节点图（进入地图）** | 迷雾汇聚加载动画（~1.5s）——全屏墨色晕染收拢为节点图轮廓，随后揭雾 |
| **节点图→地图选择（返回）** | 淡出过渡（~0.5s），节点图溶解为墨色粒子 |
| **节点图→战斗/事件/商店** | 与 combat-ui 规范一致的战斗切换过渡（节点图暗化→场景切换） |
| **战斗/事件/商店→节点图** | 短暂淡入（~0.5s），当前节点标记已访问（节点状态翻转动画） |

### 屏幕内状态变更动画

| 动画 | 触发 | 规格 |
|---|---|---|
| **揭雾动画** | 移动到新节点 | 迷雾消散 ~0.8s，揭示节点弹入（scale 0.8→1.0，ease-out） |
| **玩家标记移动** | 点击可达节点 | 沿路径的移动动画（~0.4s/节点），途经节点依次点亮 |
| **AP 数值变化** | 移动消耗 AP | 数字滚动动画（~0.3s）+对应分段格熄灭，颜色阈值切换时短暂脉冲 |
| **AP 危急闪烁** | AP ≤10% | 红色边框呼吸闪烁（1.2s 周期），音效同步 |
| **节点悬停放大** | 悬停 | scale 1.0→1.1（~0.15s），tooltip 淡入 |
| **弹窗打开** | 节点交互 | 弹窗从目标节点位置缩放弹出（scale 0.9→1.0 + 淡入，~0.2s） |
| **弹窗关闭** | 取消 | 缩回收起（~0.15s） |
| **Boss 邻近呼吸** | Boss 同层/相邻 | Boss 图标发光呼吸（2s 周期） |
| **通关结算进入** | Boss 击败返回 | 全屏金色光晕展开→结算面板浮现（~1s） |
| **探索结束面板进入** | AP 归零/主动结束 | 淡入+轻微下沉感（~0.4s） |

### 减少动态

- 所有动画支持 `减少动态` 设置：动画时长压缩至 ≤0.1s 或改为瞬时状态切换
- 揭雾动画在减少动态下改为瞬时揭示+一次性边缘高亮
- AP 危急闪烁在减少动态下改为静态红色边框（不闪烁），改用 HUD 边缘细红线常驻提示

## Data Requirements

| 数据 | 源系统 | 读 / 写 | 备注 |
|---|---|---|---|
| 节点图结构（节点/路径/层数） | 探索系统 | 读 | 地图生成后只读；重入时生成新图 |
| 当前节点位置 | 探索系统 | 读 | 显示玩家标记；`node_entered` 事件触发系统更新 |
| 可达节点集合 | 探索系统 | 读 | 每次移动后刷新高亮状态 |
| 迷雾状态（已揭示区域） | 探索系统 | 读 | 揭雾动画由移动事件驱动 |
| 节点类型详情（敌人构成/商品/效果） | 探索系统 + 战斗系统（敌人数据）+ 资源系统（商品） | 读 | 悬停预览与弹窗内容 |
| Boss 推荐战力 / 玩家当前战力 | 战斗系统（战力评估公式） | 读 | Boss 确认弹窗对比显示 |
| AP 当前值/最大值 | 行动力系统 | 读 | 显示用；消耗由探索系统在 `node_entered` 时写入 |
| AP 颜色阈值 | 行动力系统（调优旋钮） | 读 | >30% 蓝 / >10% 黄 / ≤10% 红 |
| 地图列表（名称/难度/解锁状态/通关状态/境界要求） | 游戏状态管理器 | 读 | 地图选择界面卡片数据 |
| 重入费用 | 资源系统（调优旋钮） | 读 | 重入确认弹窗显示 |
| 灵石余额 | 资源系统 | 读 | 地图选择顶部+重入弹窗；扣除由资源系统执行 |
| 通关奖励内容（常规+首次通关额外） | 探索系统 + 资源系统 | 读 | 结算面板分段展示 |
| Boss 遭遇状态（本次探索） | 探索系统（会话统计） | 读 | 探索结束面板 Boss 状态行 |
| 本次探索收集摘要（灵石/卡牌/修为增量） | 游戏状态管理器（会话统计） | 读 | 探索结束面板；增量统计由各系统上报 |
| 卡组列表（只读） | 卡牌系统 | 读 | 卡组查看面板（含筛选排序与卡牌详情） |
| 境界/修为/卡组数量 | HUD（同数据源） | 读 | 底部 HUD 条，本规范不重复定义 |
| 教程已完成标记 | 游戏状态管理器 | 读 | 首次教程覆盖判断 |

**更新频率说明**：
- 节点图数据：事件驱动——仅在 `node_entered`（移动）、节点交互完成返回时刷新，无实时轮询
- AP 显示：事件驱动——AP 变化信号（`ap_changed`）触发数字滚动动画
- 灵石余额：事件驱动——交易/奖励入账信号触发

**空值处理**：
- 节点详情不可用（如迷雾节点悬停）→ tooltip 仅显示「？」图标，不显示敌人构成
- 收集摘要无数据（如 AP 归零时一步未走）→ 显示「本次探索无收获」占位文案
- 地图列表为空（理论不可能，新档至少 1 张）→ 防御性显示「无可用地图」+错误上报

**架构关注点**：本 UI 不拥有任何游戏状态——全部只读，所有变更通过事件触发对应系统执行。

## Accessibility

基线：WCAG-AA（对比度 ≥4.5:1），信息不依赖单一颜色传达。

### 键盘导航
- 完整键盘路径：顶部条按钮 → 可达节点（按层从左到右）→ HUD 卡组入口，Tab 前进 / Shift+Tab 后退
- 节点导航辅助：方向键在节点间按空间关系跳转（↑上一层 / ↓下一层 / ←→ 同层相邻），Enter 确认
- 弹窗内：Tab 循环焦点限制在弹窗内（焦点陷阱），ESC 取消
- 空格键视图复位——不与节点确认冲突（确认专用 Enter）

### 手柄导航
- 方向键/摇杆移动虚拟光标；A=确认、B=取消、Start=暂停、LB/RB=缩放
- 无需鼠标精度：节点点击判定半径 ≥24px（大于图标本体），虚拟光标有磁性吸附（靠近节点时轻微吸附）

### 对比度与文本
- 节点文字标签、AP 数字、弹窗正文：暖白 #f5f0eb 于深色背板，对比度 ≥4.5:1
- 最小字号：节点标签 14px（100% 缩放下）、正文 16px、AP 大号数字 32px
- 50% 缩放时隐藏节点文字标签（见 States & Variants）——避免低于可读阈值的文字渲染

### 不依赖颜色的传达
- **AP 状态**：蓝/黄/红颜色之外，黄色阶段附「行动力偏低」文字、红色阶段附「行动力告急」文字+图标（⚠）
- **节点可达性**：可达=高亮+呼吸描边动画+悬停光标变手型；不可达=灰显+禁用光标；不仅靠亮度区分
- **节点类型**：10 类节点用图标+颜色双编码（沿用 combat-ui 图标+悬停文字模式）
- **锁定地图卡片**：锁图标+灰显双编码，tooltip 文字说明解锁条件

### 动画替代
- AP 危急闪烁、揭雾动画、Boss 呼吸均有减少动态替代方案（见 Transitions & Animations 的「减少动态」段）
- 玩家标记移动动画在减少动态下改为瞬时位置切换

### 屏幕阅读器考虑
- 节点获得键盘焦点时播报：「第 2 层，战斗节点，可达，行动力消耗 1」
- AP 变化播报：「行动力 12」；状态阈值切换时播报警告文字

## Localization Considerations

**语言现状**：中文为源语言（Primary）。本节按可预见的本地化风险记录约束。

### 文本膨胀风险元素

| 元素 | 中文示例 | 最大字符预留 | 优先级 |
|---|---|---|---|
| 节点 tooltip 类型名 | 「精英战斗」 | 4 字 → 预留 +40%（6 字宽度） | 高（缩放 50% 时空间紧张） |
| 节点 tooltip 详情行 | 「剑修·青云 HP 45」 | ~12 字 → 预留 16 字宽度 | 高 |
| AP 状态文字 | 「行动力偏低」 | 5 字 → 预留 7 字宽度 | 中（旁侧有空间） |
| 地图名称（卡片） | 「青云剑宗」 | 4-6 字 → 预留 8 字宽度 | 高（卡片标题单行） |
| 地图卡片境界要求 | 「需筑基期」 | ~5 字 → 预留 7 字宽度 | 中 |
| 弹窗按钮 | 「进入战斗」「确认传送」 | 4 字 → 预留 6 字宽度 | 中（按钮可横向扩展） |
| toast 提示 | 「行动力不足」 | ~8 字 → 预留 12 字宽度 | 低（横幅可换行） |
| 教程覆盖文案 | 3 步说明 | 每步 ~15 字 → 预留 21 字 | 低（覆盖层空间充足） |

### 布局关键约束

- **地图卡片标题必须单行**：卡片 360px 宽度下，标题区按 8 个中文字符宽度（~128px @16px 字号）预留——超过则截断+tooltip 完整显示
- **AP 大号数字**：数字+斜杠格式（12/20）不翻译，但「行动力」标签文字预留 7 字宽度
- **节点文字标签**：100% 缩放下节点旁标签最多 6 字符宽度——类型名超长语言（如德语 „Elitekampf"）在 100% 缩放下降级为仅图标（与 50% 缩放行为一致），悬停 tooltip 显示全名
- **日期/数字格式**：灵石数量使用千位分隔符（区域设置感知：1,240 中文/英文，1.240 德语）；无日期显示

### 不翻译元素

- 节点类型图标、AP 数值、灵石图标、✕/ⓘ/暂停图标
- 玩家标记、迷雾视觉

## Acceptance Criteria

QA 测试人员可直接验证，无需阅读其他设计文档：

- [ ] 从地图选择点击卡片到节点图完全可交互，加载时间 ≤2s（含迷雾汇聚动画）
- [ ] 节点图在 1920×1080 下默认整图适配显示，所有节点无遮挡可见
- [ ] 10 种节点类型（入口/战斗/精英/Boss/事件/商店/传送/灵泉/渡劫台/回复点）均有独特图标+颜色，悬停显示类型名
- [ ] 悬停可达节点时，0.3s 内浮出 tooltip，显示节点类型、AP 消耗；战斗类节点显示敌人构成
- [ ] 点击可达节点：玩家标记沿路径移动（≤0.5s/节点），AP 扣减数字滚动，迷雾按规格揭示
- [ ] 点击不可达节点：节点抖动+toast 显示「行动力不足」或「路径不可达」，不发生移动
- [ ] AP 显示：分段格与数字一致（每格=1 AP，消耗时熄灭），颜色阈值正确：>30% 蓝 / >10% 黄 / ≤10% 红+闪烁；黄色/红色阶段伴随文字+图标（不依赖颜色单独传达）；悬停 AP 显示详情（当前/最大/已消耗）
- [ ] Boss 节点交互：确认弹窗含推荐战力对比（推荐战力/我的战力）与 80% 修为损失类危险警示（朱砂红高亮）与撤退选项
- [ ] 滚轮缩放在 50%-150% 间平滑变化；50% 时节点文字标签隐藏；空格键视图复位
- [ ] 行动力归零后 ~1s 内自动弹出探索结束面板，显示收集摘要与 Boss 状态行（未遭遇——到达第 X/Y 层 / 已遭遇——结果）；摘要为空时显示「本次探索无收获」
- [ ] 点击「✕结束探索」弹出确认弹窗；确认后进入探索结束面板
- [ ] 重入已通关地图：确认弹窗显示扣费金额与当前灵石；「确认传送」后灵石扣减、生成新节点图
- [ ] 通关结算面板区分常规通关奖励与首次通关额外奖励（重入通关时不显示首次奖励段）
- [ ] 卡组查看面板支持按费用/类型筛选排序，点击卡牌弹出卡牌详情
- [ ] Boss 节点交互：确认弹窗含 80% 修为损失类危险警示（朱砂红高亮）与撤退选项
- [ ] 锁定地图卡片灰显+锁图标，悬停显示解锁条件
- [ ] 纯键盘导航可达所有交互元素：顶部条按钮→节点（方向键空间跳转）→HUD 入口，焦点环清晰可见
- [ ] 手柄虚拟光标可完成节点选择与弹窗操作，节点点击判定半径 ≥24px 带磁性吸附
- [ ] 开启「减少动态」后：揭雾改为瞬时揭示、AP 危急改为静态红边框，无闪烁动画
- [ ] 弹窗打开时节点图输入冻结（缩放/平移/点击无效）；ESC 关闭弹窗返回节点图
- [ ] 首次进入地图时教程覆盖显示（3 步提示），任意点击跳过；第二次进入不再显示

**覆盖检查**：性能 1 条、导航 2 条（键盘+手柄）、错误/空状态 3 条、无障碍 3 条、核心目的（路线规划）5 条、GDD 细节补全 4 条（AP 分段格+悬停详情、推荐战力、Boss 状态、首次通关奖励、卡组筛选）。
