## 全局技术参数与红线

| 参数 | 值 |
|------|-----|
| 实现方式 | **程序化动效为主**（Tween/AnimationPlayer + CanvasItem 绘制）——水墨特效是笔触与晕染，非粒子雾；斩击感以手绘笔触 sprite 表现而非纯粒子系统（§参考《胧村正》） |
| 粒子上限 | 战斗 HUD 特效粒子 ≤10 draw calls（§8.3——战斗 HUD 总预算 80 含飘字 ~10） |
| 色彩纪律 | 同屏色彩种类 ≤3（不含灰阶）；语义色同时出现总量 ≤12 处（朱砂红 ≤5 / 松石青 ≤4 / 琉璃金 ≤3） |
| 动画时长标准 | 微交互 150ms / 小过渡 300ms / 中过渡 500ms / 大过渡 800ms / 场景切换 1200ms（§7.4）；**>300ms 的动画必须可点击跳过或纯装饰** |
| 渲染器风险 | D3D12 下 CPUParticles2D + modulate.a 混合模式需烟雾测试；自定义 glow shader 需测试（combat-ui-system §渲染风险） |
| Z 层级 | 特效独立一层（背景/游戏对象/UI/特效/模态，共 ≤5 层） |
| 色盲后备 | 渡劫雷光以亮度峰值补偿（金雷光比白色亮 15-20%）；稀有发现用环形波纹粒子模式 + 屏幕震动（形状冗余） |
| 文件组织 | `src/ui/vfx/` 纯 GDScript 动效类 + `assets/vfx/sprites/` 少量笔触 sprite（PNG 序列，命名 `vfx_[effect]_[frame].png`） |

## ASSET-327 — 命中/伤害特效（伤害飘字）

| 字段 | 值 |
|-------|-------|
| 类别 | VFX / 程序动效 + Label |
| 触发 | 攻击结算（阶段 4，按速度顺序） |
| 规格 | 弹出式数字，从目标位置向上飞升 40px，0.6s 淡出 |
| 颜色 | 朱砂红（§4.2 生命/伤害语义色） |
| 字号分档 | 1-9→24px / 10-99→28px / 100+→32px |

**视觉描述**：数字自目标头顶弹出，向上飞升 40px 后淡出，全程 0.6s。颜色一律朱砂红——不用「红色」泛称，色值锚定 §4.2。多段伤害合并显示。

**冲突裁决**：combat-ui-system.md U5 写「向下掉落、红色」——与美术圣经 A11「向上飞升、朱砂红」冲突，**按美术圣经裁决：向上飞升 + 朱砂红**。死亡浮字 story（combat-ui 003）已实现上飘方向，与此一致。

## ASSET-329 — 角色阵亡消散特效

| 字段 | 值 |
|-------|-------|
| 类别 | VFX / 程序动效（shader 或 sprite 序列） |
| 触发 | HP 归 0 |
| 规格 | 淡墨晕染消散 2-3s：清晰毛笔线条 → 淡墨晕开 → 留白；末尾一笔极克制朱砂红（面积最小，位于消散最后痕迹处） |
| 配套 | 阵位变空位虚线框 |

**视觉描述**：立绘不直接消失——以淡墨晕染形式渐次消散，表情变化与墨色消散同步；画面最后出现一笔朱砂红象征生命终点。

**冲突裁决**：combat-ui-system.md U7/U16 写「碎裂→光点消散 0.5s」——与美术圣经 §5.5「淡墨晕染 + 留白 + 一笔朱砂红」冲突，**按美术圣经裁决为晕染方案**。注意 combat-ui 003 story 已按「碎裂/沙漏淡出」口径实现 DEBT-CUI-003 文字通道，本 spec 生效后需同步登记技术债差异。

**实现提示**：AnimationPlayer 驱动 modulate + 自定义晕染 shader（dissolve 阈值 + 噪声纹理）；2-3s > 300ms 红线，须可点击跳过或压缩至纯装饰层。

## ASSET-330 — 费用消耗特效（灵力光粒消散）

| 字段 | 值 |
|-------|-------|
| 类别 | VFX / CPUParticles2D + Label 动效 |
| 触发 | 出牌扣费 |
| 规格 | 费用栏数字缩放弹跳（scale 1.0→1.3→1.0，400ms）+ 光粒自数字处向上消散（松石青微粒 ≤8 个，0.2s） |
| 变体 | 费用不足：数字朱砂红闪烁 0.3s 周期 ×3 次（§7.4 闪烁规则） |

**视觉描述**：数字弹跳同时少量松石青光粒上浮消散——微粒即灵力具象。粒子数 ≤8，计入 HUD 特效粒子 10 draw call 预算。

**技术风险**：D3D12 下 CPUParticles2D + modulate.a 混合需烟雾测试（combat-ui-system §渲染风险表）。

## ASSET-331 — 阵法部署/光环特效

| 字段 | 值 |
|-------|-------|
| 类别 | VFX / 程序动效（draw ring / shader） |
| 触发 | 阵法卡打出（0.4s 扩展）；生效期常驻光环 |
| 规格 | 部署：光环自阵法区向外扩展一圈（淡墨同心圆，0.4s）；常驻：阵法卡外发光——**正道淡墨白 / 中立淡灰 / 魔道淡墨青**（阵营无色彩编码，§4.5 纯墨） |

**视觉描述**：光环是淡墨几何同心圆的呼吸式脉动（alpha 15-30%），不使用彩色 glow。部署瞬间一圈从中心扩展即止。

**冲突裁决**：combat-ui U17「颜色对应阵营」若指彩色，违反 §4.5 阵营纯墨——**裁决为墨阶差异**。自定义 glow shader 需 D3D12 测试。

## ASSET-332 — 天劫/雷伤特效

| 字段 | 值 |
|-------|-------|
| 类别 | VFX / 笔触 sprite + 程序动效 |
| 触发 | 渡劫战开始（乌云汇聚→雷光降落→Boss 登场，1.0s）；每回合末雷伤（角色头顶雷电标记闪烁 0.3s） |
| 规格 | 闪电为**有机水墨笔触的不规则枝杈状墨迹**自上方劈下；雷光蓝白冷光（3000-3500K 当量），关键时刻闪现琉璃金微光；雷光是画面中最亮元素（可溢出白边） |
| 常驻 | 渡劫战全程角色头顶显示雷伤层数（墨白数字+雷纹小标） |

**视觉描述**：天雷以毛笔笔触绘制，不用直线闪电符号。灰度模式下以亮度峰值补偿（金雷光比白亮 15-20%）。

**素材需求**：`vfx_thunder_branch_[1-4].png` 手绘枝杈雷笔触 sprite 4 帧（512×512 透明底，白/淡墨）——AI 生图不适用（需透明底+可控笔触），程序绘制或手绘。

## ASSET-333 — 突破成功特效（丹青释放）

| 字段 | 值 |
|-------|-------|
| 类别 | VFX / 全屏程序动效 |
| 触发 | 渡劫成功（击败天劫 Boss） |
| 规格 | 乌云散开 → 金光自天而降 → 画面从黑底瞬间浸染为琉璃金 → **缓慢回落，余韵持续 3-5s** → 境界名浮现（800ms 大过渡） |
| 特权 | **全游戏唯一允许主导性色彩的状态**——琉璃金与松石青可大量出现 |

**视觉描述**：数十分钟积累换来的视觉回报——瞬间金色浸染、缓慢回落，修为条上新境界标识保持琉璃金微光。

**冲突裁决**：tribulation-system T5/T7 写 0.8-1.0s——美术圣经明确余韵 3-5s，**裁决：转场动画 800ms + 余韵层 3-5s（余韵为纯装饰不阻塞输入，符合跳过规则）**。

## ASSET-334 — 修为获取/满值特效

| 字段 | 值 |
|-------|-------|
| 类别 | VFX / 程序动效（HUD 条 + Label） |
| 触发 | 获得修为（0.3s 平滑增长 + 「+50 修为」上飘字）；修为满（闪烁 + 发光边框 + 「修为已满」提示） |
| 颜色渐进 | 松石青随境界渐进释放：炼气 0% → 筑基/金丹渐增 → 元婴灵力微粒 → 化神修为条全青填充+琉璃金点缀（金 ≤5%） |

**视觉描述**：修为条是「灵力流转」的具象——低境界近墨白，随境界升高松石青占比提升，化神达成青金双色（全游戏唯一双色进度条，与境界图标 ASSET-275 呼应）。

## ASSET-336 — 攻击目标选择特效（脉冲/箭头/瞄准线）

| 字段 | 值 |
|-------|-------|
| 类别 | VFX / 程序动效（draw line + 脉冲） |

## ASSET-337 — 探索节点/迷雾特效

| 字段 | 值 |
|-------|-------|
| 类别 | VFX / 程序动效 |
| 触发 | 地图加载（节点逐层展开 800ms，连线自入口向 Boss 延伸）；移动（标记沿线滑行 300ms，连线落笔 300ms）；迷雾揭示（当前层+3 内可见） |
| 过渡 | 节点图↔场景插图：几何元素「溶解」为有机墨迹晕染再凝练，0.4-0.6s |
| 色彩 | **节点图纯墨白**（§6.4.2）——Boss 节点以最粗边框+裂隙符号表达分量，不用金色光环；已访问节点淡墨对勾 |

**冲突裁决**：exploration E4「金色脉动光环」、E5「绿色边框」违反节点图无色彩铁律——**裁决为墨阶/线宽编码**。可达节点外发光用淡墨白。

## ASSET-338 — 胜利/失败结算特效

| 字段 | 值 |
|-------|-------|
| 类别 | VFX / 程序动效 + 布局动画 |
| 胜利 | 战利品卡以**墨色晕染卷轴**一字排开，每张从模糊到清晰翻开；修为条墨色填满后朱砂红点缀数字；全屏文字 500ms 浮现 |
| 失败 | 全屏灰暗过渡 + 失败文字浮现（500ms）；保留美术圣经「墨色消散」语言（无胜利态的卷轴） |
| 地图通关 | CLEAR 文字 1.0s + 奖励逐条浮现；新地图卡片自底部弹出翻转 500ms |

**视觉描述**：胜利的仪式感来自卷轴展开的节奏，不是金色爆闪。朱砂红仅一次点缀（≤5 预算内）。

**验收锚点**：
- 同屏色彩 ≤3 种（不含灰阶）——全战斗/渡劫场景逐屏检查
- 语义色总量 ≤12 处（朱砂红 ≤5 / 松石青 ≤4 / 琉璃金 ≤3）
- 所有 >300ms 动画可跳过或纯装饰
- 灰度模式下渡劫金雷光仍为最亮元素（亮度补偿验证）
- 战斗 HUD 特效粒子 ≤10 draw calls（WTF 调试面板验证）

**跨文档冲突登记**（本 spec 裁决汇总，供 GDD 同步参考）：
1. 伤害飘字方向/颜色（U5 vs A11）→ 上飞+朱砂红
2. 治疗飘字颜色（U6 绿 vs A11 松石青）→ 松石青
3. 阵亡形态（U7 碎裂 vs A8 晕染）→ 晕染（DEBT-CUI-003 关联）
4. 出牌时长（0.3s vs 500ms）→ 500ms 四段式
5. 探索节点金色光环/绿色边框（E4/E5 vs A18）→ 墨阶编码
6. 攻击脉冲蓝色（U18）→ 淡墨白
7. 突破余韵（3-5s vs 0.8s）→ 800ms 转场 + 3-5s 余韵
