## 技术参数（全组共用）

| 参数 | 值 |
|------|-----|
| 格式 | **SVG 矢量为主文件**（美术圣经 §8.1.1——「矢量优先——UI 图标在缩放时不得模糊」）+ PNG 导出（固定尺寸显示） |
| 基准网格 | 24×24px，8px 步进（美术圣经 §7.3.1） |
| 线条宽度 | 2px 主轮廓 / 1px 内部细节（§7.3.1）；悬停态 3px |
| 圆角 | 2px（§7.3.1） |
| 线条色 | 浓墨 `#1a1a1a` + 透明填充；激活态允许语义色填充（§7.3.1） |
| 尺寸变体 | 每图标出 24px / 32px 两档（个别 HUD 专用尺寸见分项） |
| 命名 | `ui/icons/[category]/[icon_name]_[size].svg`（§8.1.2，例 `type_role_24.svg`） |
| 图集 | 卡牌类型/状态效果/节点三组各合并 PNG 图集（§8.2.3——`card_type_atlas.png` 512×256 / `status_atlas.png` 256×256 / `node_atlas.png` 256×128） |
| 交互状态 | 常态（墨线框+透明）→ 悬停（3px+5% 淡墨填充）→ 激活（语义色填充+线白）→ 不可用（50% 透明+虚线）（§7.3.3） |
| 色盲安全 | 状态图标纯墨白形状区分（§3.3.3 色阶规则）；境界图标形状复杂度编码（炼气 1 形→化神 5 形，§4.8） |
| 色彩预算 | 类型色饱和度 ≤8%（§4.4）；阵营图标纯墨（§4.5）；境界图标青色渐进 + 化神微量金（§4.6） |

> **注**：UI 图标是**矢量设计资产**（Illustrator/Inkscape 手绘或程序绘制），**不适用 AI 生图**——24px 尺寸下 AI 生成的细节噪点不可控。本 spec 提供的是设计规范（形状构成/线条/色值），不是生成提示词。生产方式建议：概念设计 1 次出 SVG，程序批量导出 PNG 图集。
