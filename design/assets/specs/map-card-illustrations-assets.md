| 参数 | 值 |
|------|-----|

| Godot 导入预设 | 2D Texture，Filter=On（插画缩小显示），Mipmaps=Off，Compress=VRAM（DXT5/BC3） |
| 单张预估 | ~590KB RGBA8 未压缩 → DXT5 后 ~170KB VRAM |
| 总计预估 | 17 张 × ~170KB = ~3MB VRAM（地图选择界面整屏滚动时全驻留——预算内） |
| 上色规范 | 浅绛淡彩（美术圣经 §4.9 六色相；场景饱和度 S 30-55%，墨骨主导） |

## 缩放落盘 SOP

```python
from PIL import Image
# 地图卡：1778×2074 → 裁切至 6:7（约 1778×2074，裁切量极小）→ 360×420
src = Image.open(r'<候选件路径>/qingyun_sword_sect.png').convert('RGB')
w, h = src.size                      # 1778×2074，比例 0.8573 ≈ 6:7 (0.857)
target = 360 / 420                   # 0.8571
if w / h > target:                   # 过宽 → 裁宽
    w2 = round(h * target); left = (w - w2) // 2
    src = src.crop((left, 0, left + w2, h))
else:                                # 过高 → 裁高
    h2 = round(w / target); top = (h - h2) // 2
    src = src.crop((0, top, w, top + h2))
src.resize((360, 420), Image.LANCZOS).save(
    r'E:/mortal-heaven-question/assets/environments/maps/qingyun_sword_sect.png')
```

落盘后运行 `godot --headless --import` 生成 `.import` 侧车文件。
